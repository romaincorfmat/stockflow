# StockFlow

## Description

StockFlow is a web application for managing products, inventory and orders.

The application allows employees and managers to monitor stock levels, manage products and handle customer orders.

The project is built as a learning project with a focus on clean architecture, good development practices and professional Git workflow.

## Tech Stack

### Frontend

- React
- TypeScript

### Backend

- Node.js
- Express
- TypeScript

### Database

- PostgreSQL
- Drizzle ORM

### Development

- Git
- GitHub
- Docker
- Vitest

## Features

### Authentication

- User login
- Role-based access control

### Products

- View products
- Create products
- Update products
- Deactivate products

### Inventory

- View current stock
- Receive products
- Track stock movements
- Manage reserved stock

### Orders

- Create orders
- View orders
- Confirm orders
- Prepare orders
- Ship orders
- Track order status

## Project Goals

The main goal of this project is to build a realistic application while learning and applying professional software development practices, including:

- Clean project organization
- API design
- Database design
- Authentication and authorization
- Automated testing
- Git workflow
- Documentation
- Docker and deployment
